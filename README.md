# Concord para Windows

Baixe a versão mais recente em [Releases](https://github.com/KevynMurilo/Concord-Downloads/releases/latest).

- **Setup**: instala o Concord no Windows 10/11 x64.
- **Portable**: executável portátil, sem instalador.

Na primeira abertura, informe o endereço HTTPS do servidor fornecido pelo administrador da comunidade. O aplicativo não inclui endereço, IP ou senha. Use a bandeja do Windows para abrir e ocultar a janela compacta; a chamada pode continuar com a janela oculta.

Os executáveis ainda não têm assinatura digital comercial, portanto o Windows pode mostrar um aviso de editor desconhecido. O código-fonte fica em um repositório privado.
